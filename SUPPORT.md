# Support

## Before opening an issue

1. Use Python 3.10–3.12.
2. Pull the latest `main` branch.
3. Run `python scripts/check_project.py`.
4. Check whether the problem also occurs with a bundled demonstration.
5. Search existing issues for the same error.

## Where to ask

- Reproducible bug: use the bug-report issue form.
- Feature proposal: use the feature-request issue form.
- Security or private production data: follow `SECURITY.md`; do not post it in
  a public issue.

Support is best-effort. This repository is a demonstrator, not a commercial
quality-control service or certified production system.
