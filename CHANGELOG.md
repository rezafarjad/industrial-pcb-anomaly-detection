# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and releases use semantic versioning.

## [1.0.0] - 2026-07-28

### Added

- Runnable Streamlit inspector with bundled, attributed PCB demonstrations.
- ORB/RANSAC registration and robust color/edge anomaly localization.
- JSON and annotated-image exports.
- `pcb-inspect` command-line interface.
- Windows one-click launcher and desktop-shortcut installer.
- Docker and Compose deployment paths.
- Cross-platform automated validation, linting, packaging, and app smoke tests.
- Reproducible demo validation with genuine VisA annotations.
- Contributor, security, support, issue, and pull-request documentation.

### Changed

- Separated the runnable reference detector from the optional PatchCore research
  notebook.
- Removed embedded notebook outputs and obsolete temporary-tunnel code.
- Replaced placeholder asset and result folders with attributable examples and
  generated validation outputs.
